Parents Challenge CRM

This web-application will provide a front-facing UI for staff and parents at nonprofit Parents Challenge 
to interact with to manage their information and data pertaining to the program. Parents will be able to 
view their family profile, program events and session registration, as well as track their attendance. Staff
will be able to manage data, such as family records over the course of the organization's history, view attendance
records, update family profiles, and create reports without needing to know SQL to interact with the database in the backend.

Techstack:
HTML/CSS, Typescript, Supabase 

How to Run:
npm run dev
